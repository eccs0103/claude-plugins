# eccs0103 plugins

A [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugin-marketplaces).

[Change log](./CHANGELOG.md)

## Setup

```
/plugin marketplace add eccs0103/claude-plugins
```

## Plugins

| Plugin                                           | What it does                                                                                       | Install                                   |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| [product-vision](./plugins/product-vision/)      | Collects a project's product decisions into `docs/product/` and makes every agent follow them.     | `/plugin install product-vision@eccs0103` |
