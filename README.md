# eccs0103

A [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugin-marketplaces).

[Change log](./CHANGELOG.md)

## Setup

Send the plugin's install command in a Claude Code session. In Claude Desktop, type it in the prompt box of the **Code** tab. Each plugin's page lists what it needs first.

## Plugins

| Plugin                                           | What it does                                                                                       | Install                                                                  |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| [product-vision](./plugins/product-vision/)      | Collects a project's product decisions into `docs/product/` and makes every agent follow them.     | `/plugin install product-vision --marketplace eccs0103/claude-plugins`   |
